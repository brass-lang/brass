# The language reference for models

`BRASS-REFERENCE.md` is a condensed language reference for models editing Brass. It pairs rules with examples and names its revision on the first line. This copy is r33.

To try Brass with a model, provide this file and the `brass` tool. The [specification](../../docs/brass-core-spec.md) takes precedence if they disagree.

The snapshot's [materials](../snapshot-20261019/materials/) contain the compact and full references supplied to each setup. Those copies preserve the wording and tool instructions used in the trial.
